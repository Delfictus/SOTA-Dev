PHASE 1: NHS FUSED ENGINE DEBUGGING
================================================================================

PROBLEM IDENTIFIED:
- NHS fused engine producing NaN coordinates in ensemble PDBs
- Original speed: ~550 steps/sec but unusable due to NaN
- Alternative AmberMegaFusedHmc with PME: ~44 steps/sec (too slow)

ROOT CAUSE ANALYSIS:
- Created diagnostic tool: crates/prism-nhs/src/bin/nhs_diagnose.rs
- Found positions exploded around step 84-211 before NaN appeared
- Root cause: insufficient Langevin damping (gamma_base=1.0 ps^-1 was too weak)
- Physics: c1 = exp(-gamma * dt) = exp(-1.0 * 0.002) = 0.998
- This means 99.8% velocity retained per step - virtually no damping!

FIX APPLIED (3 parts):

1. Equilibration friction boost in fused_engine.rs (lines 1076-1108):
   - EQUILIBRATION_GAMMA = 1000.0 ps^-1 (extreme damping)
   - Exponential decay from 1000 -> 10 ps^-1 over first 10,000 steps
   - Formula: gamma = 1000 * exp(-3 * progress) + 10 * (1 - exp(-3 * progress))

2. Base friction increase in fused_engine.rs (line 989):
   - Changed gamma_base from 1.0 to 10.0 ps^-1
   - New c1 = exp(-10.0 * 0.002) = 0.98 -> 2% damping per step

3. Force/velocity clamping in nhs_amber_fused.cu (lines 945-990):
   - MAX_FORCE = 1000 kcal/mol/Å
   - MAX_VELOCITY = 100 Å/ps
   - Prevents numerical blowup from unminimized structures

RESULT:
- NHS engine now runs at 1690-2476 steps/sec
- Coordinates stable for ~77 frames before thermal protocol instability
- 40-55x speedup over PME-based generator

PHASE 5: SPIKE DETECTION TUNING
================================================================================

PROBLEM:
- LIF_THRESHOLD = 5.0 was too high
- Spike signal math:
  * Water density range: 0 → 0.0334 molecules/Å³
  * Max density change per step: ~0.01-0.02
  * After noise floor (0.005): ~0.005-0.015
  * Signal multiplier 5x: ~0.025-0.075 per step
  * Need ~70+ steps of MAX signal to fire ONE spike
  * With decay (tau=0.5), practically impossible

FIX APPLIED in nhs_amber_fused.cu:

1. LIF_THRESHOLD: 5.0 → 0.5 (10x lower)
2. NOISE_FLOOR: 0.005 → 0.002 (2.5x more sensitive)
3. Signal amplification: 5x → 10x (2x stronger)
4. EXCLUSION_NOISE_FLOOR: 0.01 → 0.005 (2x more sensitive)
5. Exclusion signal: 2x → 5x (2.5x stronger)
6. Tau decay: 0.5x → 1.5x (3x slower decay, more accumulation)
